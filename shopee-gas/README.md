# 쇼피 자동화 (Google Sheets + Apps Script, 전부 무료)

구글 시트 하나가 관리 화면이자 서버예요. 서버 비용, AI 비용 없이 돌아가요.

```
월요일 06시   수요 조사    Gemini + 구글 검색 → 팔리는 한국 상품 → '소싱키워드' 자동 갱신
매일 07시     상품 소싱    도매꾹에서 키워드로 상품 찾기 → 상품 시트에 '대기'로 추가
매시간        상품 등록    가격 계산 + AI 상품글(7개국 언어) + 위험도 점검 → 쇼피 업로드 (하루 30개)
30분마다      주문 확인    새 주문 → 주문 시트 + 발주 메일 (도매처 링크·수량·발송기한)
30분마다      채팅 응대    배송·상품 질문은 AI가 바로 답장 / 취소·환불·불만은 초안 + 메일로 넘김
```

## 무료 한도 (개인 Gmail 기준)

- Apps Script: 자동 실행 하루 총 90분, 1회 6분. 이 구성은 하루 30~40분 정도 써요.
- Gemini 무료 등급: 분당·일일 호출 수 제한이 있어요. 상품 30개 + 채팅 수십 건은 보통 범위 안이에요. 한도는 [AI Studio](https://aistudio.google.com)에서 확인하세요.
- 주의: Gemini 무료 등급으로 보낸 내용은 구글이 서비스 개선에 쓸 수 있어요. 고객 개인정보(주소·전화)는 AI에 보내지 않도록 짰어요.

## 설치 (처음 한 번, 약 20분)

### 1. 시트와 코드
1. [sheets.new](https://sheets.new)로 새 구글 시트를 만들어요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 이 폴더의 `.gs` 파일 10개를 같은 이름으로 만들어 붙여넣어요. `appsscript.json`은 프로젝트 설정에서 "매니페스트 파일 표시"를 켜고 덮어써요.
4. 저장 후 시트를 새로고침하면 **🛒 쇼피** 메뉴가 생겨요. **① 초기 설정**을 실행해요. 처음엔 권한 승인 창이 떠요.

### 2. 키 넣기
Apps Script **프로젝트 설정 → 스크립트 속성**에 추가해요.

| 이름 | 어디서 받나 |
|---|---|
| `SHOPEE_PARTNER_ID`, `SHOPEE_PARTNER_KEY` | [open.shopee.com](https://open.shopee.com) 개발자 앱 (셀러 승인과 별개, 쇼피코리아 담당자에게 문의하면 빨라요) |
| `GEMINI_API_KEY` | [aistudio.google.com](https://aistudio.google.com) → Get API key (무료) |
| `DOMEGGOOK_API_KEY` | 도매꾹 오픈API 신청 (무료). 없으면 자동 소싱만 꺼지고 나머지는 동작해요 |

### 3. 쇼피 연결
1. Apps Script **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 나만). 배포 URL을 쇼피 개발자 앱의 **Redirect URL**에 등록해요.
2. 시트 메뉴 **② 쇼피 인증하기** → 링크 열기 → **메인 계정**으로 승인 → "인증 완료"가 뜨면 성공이에요.
3. **③ 연결된 샵 불러오기** → 국가 시트에 `shop_id`가 채워져요.

### 4. 요율 확인 후 켜기
1. **국가** 시트의 수수료·배송비는 **예시값**이에요. 쇼피코리아 요율표대로 고쳐요.
2. **설정**에서 `하루등록수`를 **1**로 두고 `verified`를 체크해요. 그다음 **지금 실행: 상품 등록**으로 1개만 올려 셀러센터에서 확인해요.
3. 문제없으면 `하루등록수`를 30으로 바꾸고 **▶ 자동 실행 켜기**를 눌러요.

`verified`를 체크하기 전에는 업로드 없이 **미리보기**(가격 + AI 상품글)만 시트에 채워져요. 먼저 이걸로 품질을 확인하세요.

## 시트 설명

| 시트 | 내용 |
|---|---|
| 설정 | 하루 등록 수, 마진, 발송일, 채팅 자동답변 등 |
| 국가 | 판매 국가 켜기/끄기, 수수료, 배송비, shop_id |
| 상품 | 직접 넣어도 되고 소싱이 자동으로 채워요. 상태: 대기 → 미리보기/등록완료/건너뜀/오류 |
| 주문 | 새 주문이 자동으로 쌓여요. 발주 후 `발주상태`를 **발주완료**로 바꿔요 |
| 채팅 | 고객 문의와 AI 답변 기록 |
| 수요조사 | 주간 조사 결과 (점수, 근거, 출처) |
| 로그 | 실행 기록과 오류 |

## 자동으로 하지 않는 것 (일부러)

- **도매처 결제(발주):** 돈이 나가는 마지막 버튼은 사람이 눌러요. 대신 메일로 링크·수량·기한을 정리해 주고, 발송기한 24시간 전까지 미발주면 다시 알려요.
- **취소·환불·불만 채팅:** 잘못된 약속 한 번이 환불이나 페널티로 이어지기 때문에 AI는 초안만 쓰고 메일로 넘겨요.

## 실사용 전에 확인할 것

- 쇼피 API 응답 필드(카테고리 추천, 필수 속성, 판매자 채팅 권한)는 실제 응답을 보고 맞춰야 할 수 있어요. 오류는 **로그** 시트와 상품 시트 **오류** 열에 남아요.
- 카테고리마다 필수 속성(attribute)이 있으면 등록이 실패해요. 오류 메시지를 보고 속성 채우기를 추가하면 돼요.
- 도매꾹 API의 버전과 필드명은 발급 후 문서와 대조가 필요해요. 위탁판매·해외 판매·이미지 사용이 허용된 상품만 쓰세요.
- 새 샵은 등록 가능 상품 수 제한이 있고, 예약판매는 비율 제한이 있어요. 셀러센터에서 확인하세요.
