# ⛪ 와드 성찬식 자동화 (Google Apps Script)

감독단 구글 시트(성찬식 일정 · 성찬 축복/전달)를 **읽기만** 해서 알림을 보내고, 「성찬식 아젠다」 문서를 매주 채웁니다.

| 언제 | 무엇을 | 어디로 |
|---|---|---|
| 월 09:00 | 공용 「성찬식 아젠다」 문서 **맨 위에 이번 주 칸 추가** (지난주 칸 형식 그대로 복사 → 성찬식 순서표 값으로 채움) | 구글 문서 |
| 일 07:00 | **다음 주** 임무 요약 · 맡은 분별 **부탁/리마인드 메시지** · 앞으로 8주 **미정 순서** 경고 | 이메일 + 카톡(나에게) |
| 토 15:00 | 장로정원회 톡방용 **내일 성찬 축복·전달 공지문** | 이메일 + 카톡(나에게) |

- 원본 시트는 **절대 고치지 않습니다.** 선교·성역 등 민감한 탭은 읽지 않습니다 (호칭용 명단 탭의 '이름' 열만 참고).
- 금식간증 주일은 말씀 부탁을 건너뛰고, 사회 칸에 '대회'가 들어간 주(연차대회·스테이크 대회)는 아젠다를 만들지 않습니다.
- 이름은 장로정원회 → 형제님, 상호부조회 → 자매님, 청년독신성인 → 성별로 호칭을 붙입니다. 명단에 없는 이름은 그대로 둡니다.

> 월요일 이후 시트 순서가 바뀌면 메뉴의 **지금 만들기/갱신: 이번 주 아젠다**를 누르세요.
> 이미 만든 칸의 순서 값만 시트에 맞춰 고치고, 광고·행사 내용은 그대로 둡니다.

## 설치 (약 10분)

1. 내 드라이브에 **새 구글 시트**를 만듭니다 (예: "성찬식 자동화"). 감독단 시트에는 아무것도 붙이지 않습니다.
2. **확장 프로그램 → Apps Script**를 열고, 기본 `Code.gs` 내용을 모두 지운 뒤 **`전체코드.gs`** 내용을 통째로 붙여넣습니다.
   - ⚙️ 프로젝트 설정 → "appsscript.json 표시"를 켜고 `appsscript.json`도 붙여넣습니다 (시간대: 서울).
3. 시트를 새로고침하면 **⛪ 성찬식 자동화** 메뉴가 생깁니다. **1. 초기 설정**을 누르고 권한을 허용합니다.
4. `설정` 탭에 다음 주소를 붙여넣습니다.
   - **원본 시트**: 감독단 시트 주소
   - **아젠다 문서**: 공용 「성찬식 아젠다」 문서 주소 (편집 권한 필요)
     - 맨 위 주 칸을 복사해 그 위에 붙이고 값만 바꿉니다. 금식간증 주처럼 줄이 빠진 칸은 건너뛰고 줄이 다 있는 칸을 복사합니다.
   - (매주 새 문서를 만들고 싶다면 `아젠다 방식`을 **새 문서**로 바꾸고 **아젠다 템플릿**에 복사할 문서 주소를 넣으세요.)
5. 메뉴의 **미리보기**로 메시지를 확인합니다. 아무것도 보내지 않고 화면에만 보여 줍니다.

## 카카오톡 연결 (선택)

1. https://developers.kakao.com → **내 애플리케이션 → 애플리케이션 추가**
2. **카카오 로그인** ON, Redirect URI에 `https://localhost` 등록
3. **동의항목**에서 "카카오톡 메시지 전송(talk_message)"을 선택 동의로 설정
4. **플랫폼 → Web**에 `https://docs.google.com` 등록
5. 메뉴의 **2. 카카오톡 연결** → REST API 키 입력 → 로그인 후 주소창의 `code=` 값 붙여넣기

> 카카오는 단톡방 자동 게시 API를 열어주지 않습니다. 그래서 **내 카톡으로 받아서 → 전달** 방식입니다.
> 부탁 메시지는 사람마다 따로 오니, 각각 그분께 **전달**하면 됩니다. 긴 글은 200자 단위로 나눠서 옵니다.

## 바꾸고 싶을 때

| 바꿀 것 | 위치 |
|---|---|
| 아젠다 찬송 모양 · 호칭 | `설정` 탭 → 찬송 형식 (`{번호}장 - {제목}`), 아젠다 호칭 (예/아니오) |
| 부탁 메시지 문구 | `설정` 탭 → 부탁 메시지 (`{이름} {날짜} {역할} {주제} {와드}`) |
| 말씀 주제도 보내기 | 원본 시트 성찬식 탭에 **'말씀 주제'** 열을 추가하면 자동 포함 |
| 실행 요일·시각 | `Config.gs`의 `SCHEDULE` → 메뉴 **자동 실행 다시 설치** |
| 내년 탭 | 자동 (`{년}년 성찬식` → 2027년 성찬식) |

## 구조

```
[감독단 시트] ──읽기──▶ Source.gs (병합 칸 펼치기 · 날짜 찾기 · 호칭)
                           │  getMeeting_(주일) → { 사회, 말씀, 기도, 찬송, 축복, 전달 … }
                           ▼
              Jobs.gs (일: 다음 주 / 토: 내일 공지)    Agenda.gs (월: 문서 맨 위에 추가)
                           │
                           ▼
              Notify.gs ──▶ Gmail / Kakao.gs      설정 · 발송기록 = 내 시트
```

| `sendOrganistList` | 매달 25일 9시 | 다음 달 **지휘·반주·찬송표 이미지(PNG)**를 메일로 (반주자 톡방에 올리기) |
