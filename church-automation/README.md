# ⛪ 교회 업무 자동화 (Google Apps Script)

| 언제 | 무엇을 | 어디로 |
|---|---|---|
| 토 20:00 | 내일 주일 **말씀 주제·본문·핵심구절** | 이메일 + 카카오톡(나에게) |
| 매일 07:00 | 이번 주 **핵심구절 + 기도제목**(돌아가며 5개) | 이메일 + 카카오톡(나에게) |
| 목 09:00 | **성찬식 순서 구글 문서** 갱신 + 미정 담당자 알림 | 구글 문서 + 알림 |

입력은 구글 시트 한 곳(`주간말씀`, `기도제목`, `성찬식` 탭)에서만 합니다.

## 설치 (약 10분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다 (예: "교회 자동화").
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 이 폴더의 `.gs` 파일 6개를 같은 이름으로 만들어 내용을 붙여넣습니다 (기본 `Code.gs`는 지워도 됩니다).
   - `appsscript.json`은 ⚙️ 프로젝트 설정 → "appsscript.json 표시"를 켠 뒤 붙여넣습니다. 시간대가 서울로 맞춰집니다.
4. 시트를 새로고침하면 **⛪ 교회 자동화** 메뉴가 생깁니다. **1. 초기 설정**을 누르고 권한을 허용합니다.
   - 탭 4개, 예시 데이터, 성찬식 문서, 자동 실행 예약이 한 번에 만들어집니다.
5. `설정` 탭에서 **교회 이름**과 **알림 이메일**을 고칩니다 (여러 명이면 쉼표로 구분).

## 카카오톡 연결 (선택)

1. https://developers.kakao.com 에 로그인 → **내 애플리케이션 → 애플리케이션 추가**
2. **카카오 로그인** 활성화 ON, Redirect URI에 `https://localhost` 등록
3. **동의항목**에서 "카카오톡 메시지 전송(talk_message)"을 선택 동의로 설정
4. **플랫폼 → Web** 사이트 도메인에 `https://docs.google.com` 등록 (카톡 '자세히 보기' 버튼 링크용)
5. 시트 메뉴에서 **2. 카카오톡 연결** → REST API 키 입력 → 안내대로 로그인한 뒤 주소창의 `code=` 값을 붙여넣기

> **단톡방은 왜 자동으로 안 되나요?**
> 카카오는 스팸 방지를 위해 개인 개발자에게 **단체 대화방 자동 게시 API를 열어주지 않습니다.**
> 그래서 "내 카톡으로 받기 → 단톡방에 **전달** 한 번"이 무료로 가능한 가장 짧은 경로입니다.
> 교인 개개인에게 자동 발송까지 원하면 **카카오톡 채널 + 알림톡**(Solapi 같은 대행사, 건당 약 10원, 고유번호증 필요)을 써야 합니다.

## 바꾸고 싶을 때

- 시간·요일: `Config.gs`의 `SCHEDULE`를 고친 뒤 메뉴에서 **자동 실행 다시 설치**를 누릅니다.
- 성찬식 순서·체크리스트: `Config.gs`의 `COMMUNION_ORDER`, `COMMUNION_CHECKLIST`
- 기도제목 중 `공개`를 **비공개**로 두면 알림에 나가지 않고, `상태`를 **응답**으로 바꾸면 목록에서 빠집니다.

## 구조

```
[구글 시트: 입력]  →  [Jobs.gs: 언제·무엇을]  →  [Notify.gs: 어디로]  →  Gmail / Kakao.gs
      ↑                      ↑
  Util.gs (읽기·날짜)    Setup.gs (트리거 = 예약 실행)
```
