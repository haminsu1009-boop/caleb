# 선박 추적 + 알림 봇 — 구글 앱스 스크립트(GAS) 버전

서버도, 구글 시트도 필요 없습니다. **브라우저로 직접 여는 조회
페이지**(유니패스 알림봇 앱처럼 모선명/항차를 입력하는 화면)와,
기존 텔레그램 봇이 같은 배포 하나를 같이 씁니다. 데이터는 스크립트
자체 저장소(PropertiesService)에 둡니다.

- **웹에서 조회**: 배포 URL을 열면 모선명/항차 입력 폼이 뜬다 (신규)
- **텔레그램 알림**: `/watch`로 선박을 등록해두면, 관리자가 `/update`로
  정보를 갱신할 때마다 자동으로 알림이 온다 (그대로 유지)

로직은 `vessel/`(파이썬)과 같고, Node.js로 18개 시나리오를
시뮬레이션해서 검증했습니다.

---

## 배포 방법 (10분)

### 1. 독립 스크립트 프로젝트 만들기 (시트 없음)

1. [script.new](https://script.new) 접속 (구글 로그인 상태여야 함) — 바로 빈 Apps Script 프로젝트가 열립니다
2. 프로젝트 이름 정하기 (좌상단, 예: "선박추적봇")
3. 기본 `Code.gs`를 지우고, 이 폴더의 **파일 전부**를 똑같은 이름으로
   하나씩 만들어서 내용을 그대로 붙여넣기:
   - 스크립트 파일(`+` → **스크립트**): `Code.gs`, `Parser.gs`, `Directory.gs`,
     `Store.gs`, `Watch.gs`, `Providers.gs`, `Schedule.gs`, `Formatter.gs`,
     `Tracker.gs`, `Setup.gs`, `Probe.gs`, `WebUI.gs`
   - HTML 파일(`+` → **HTML**, 확장자 `.html` 없이 이름만 입력): `WebApp`, `ProbePage`
4. 저장 (Ctrl+S)

### 2. 설정값 입력 (스크립트 속성)

왼쪽 톱니바퀴 **프로젝트 설정** → 스크립트 속성 → 속성 추가:

| 속성 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | BotFather에게 받은 토큰 |
| `TELEGRAM_ADMIN_IDS` | `/update` 등을 쓸 수 있는 chat_id (콤마구분) |
| `VESSELFINDER_API_KEY` | (선택) 있으면 실AIS, 없으면 자동 Mock |

### 3. 토큰 확인

함수 선택 드롭다운에서 `testGetMe` 선택 → ▶ 실행. 처음 실행하면
권한 승인 화면이 뜹니다(본인이 만든 스크립트라 "고급" → "이동"으로
진행). **보기 → 실행 로그**에서 봇 정보가 찍히면 정상.

### 4. 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 유형(⚙️) → **웹 앱**
3. 실행 계정: **나**, 액세스 권한: **전체(익명 사용자 포함)**
4. **배포** → 나오는 **웹 앱 URL** 복사

**이 URL을 브라우저로 열면 바로 조회 화면이 뜹니다** — 텔레그램
설정(5번) 없이도 지금 바로 씁니다. 즐겨찾기 해두거나, 사내 인트라넷/
카톡방에 링크 하나로 공유하면 됩니다.

### 5. (텔레그램 알림도 쓸 거면) 웹훅 등록

웹 조회만 쓸 거면 이 단계는 건너뛰어도 됩니다. `/watch` 알림까지
텔레그램으로 받고 싶으면:

1. 스크립트 속성에 `WEBAPP_URL` 추가 (4번에서 복사한 URL)
2. 함수 `installWebhook` 실행 → 로그에 `{"ok":true,...}` 나오면 성공
3. 확인: `getWebhookInfo` 실행

### 6. 테스트

**웹**: 배포 URL을 브라우저로 열고 `EVER GIVEN` / `0526E` 입력 →
조회. 하단 "🔌 터미널·선사 연결 진단 보기" 클릭하면 각 사이트
접속 결과도 바로 보입니다(아래 "터미널·선사 자동조회" 참고).

**텔레그램**(5번을 했다면):
```
EVER GIVEN, 0526E              ← 즉시 조회
/watch EVER GIVEN, 0526E       ← 알림 등록
```
관리자 계정으로 `/update EVER GIVEN, 0526E | 터미널=HJNC | ETB=2026-09-15 08:00`
을 보내면, 방금 `/watch`한 사람에게 자동으로 🔔 알림이 갑니다.

## 웹에서 바로 쓰기

배포 URL 하나로 두 화면을 씁니다:

| URL | 화면 |
|---|---|
| `https://.../exec` | 모선명/항차 입력 → 조회 (유니패스 스타일) |
| `https://.../exec?probe=1` | 터미널·선사 사이트 연결 진단 |

조회 결과는 `/update`로 넣어둔 수동입력이 있으면 그게 최우선으로
나오고, 없으면 터미널·선사 바로가기 링크가 나옵니다 — 텔레그램 버전과
정보 우선순위는 동일합니다.

## 명령어

| 명령 | 누가 | 설명 |
|---|---|---|
| `선명, 항차` (그냥 텍스트) | 누구나 | 지금 있는 정보 즉시 조회 |
| `/watch 선명, 항차` | 누구나 | 이 선박 정보가 갱신될 때 알림 받기 등록 |
| `/unwatch 선명, 항차` | 누구나 | 알림 해제 |
| `/mywatch` | 누구나 | 내가 등록해둔 알림 목록 |
| `/update 선명, 항차 \| 키=값 ...` | 관리자 | 터미널 정보 입력 → 저장 + watch한 사람들에게 자동 알림 |
| `/delete 선명, 항차` | 관리자 | 입력값 삭제 |
| `/list` | 관리자 | 현재 저장된 입력값 전체 확인 |

`/update`로 넣은 값은 72시간 지나면 자동으로 무시됩니다(오래된
정보를 최신인 것처럼 보여주지 않기 위함).

## 터미널·선사 자동조회 — 이번엔 진짜로 될 수도 있습니다

`vessel/`(파이썬) 버전을 만든 세션은 조직 네트워크 정책 때문에
`hjnc.co.kr`, `pnitl.com` 같은 사이트에 접속이 막혀 있어서 자동조회를
완성하지 못했습니다. **하지만 이 스크립트는 배포되면 구글 인프라에서
실행되기 때문에, 그 제약이 없을 가능성이 높습니다.**

**가장 쉬운 방법**: 배포 URL 뒤에 `?probe=1`을 붙여서 브라우저로 열기
(예: `https://.../exec?probe=1`). 각 터미널/선사 사이트에 실제로
접속해본 결과(상태코드 + 응답 앞부분)를 표로 보여줍니다. 상태가
**200**이고 그럴듯한 HTML이 보이면, **그 화면을 캡처해서 Claude에게
다시 보여주세요** — 그걸 기준으로 `Schedule.gs`에 진짜 자동조회를
완성해드릴 수 있습니다.

(스크립트 편집기 쓰는 게 더 편하면 함수 `probeAll`을 실행해서
**보기 → 실행 로그**로 같은 정보를 볼 수도 있습니다 — `Probe.gs` 참고.)

### 그다음 진짜로 필요한 것 — "검색 요청" 캡처

`?probe=1`은 그 사이트의 **첫 화면**만 가져옵니다. 실제로 "선박명 넣고
검색 버튼 누르는" 동작은 대부분 자바스크립트가 별도 요청(AJAX/XHR)을
보내서 처리하기 때문에, 첫 화면 응답만으로는 검색 자체를 자동화할
수 없는 경우가 많습니다. 확실하게 끝내려면:

1. 그 사이트를 브라우저로 열어서 실제로 선박 하나를 검색해본다
2. 개발자도구(F12) → **Network** 탭 → 방금 보낸 검색 요청을 찾아
   **"Copy as cURL"** (또는 "Copy as fetch")
3. 그 내용을 Claude에게 붙여주면 `Schedule.gs`의 해당 사이트
   `lookup()`을 실제 동작하게 완성할 수 있다

자동조회가 붙으면, 나중엔 시간 트리거(예: 30분마다)를 추가해서 값이
실제로 바뀔 때만 `/watch`한 사람에게 알림을 보내도록 확장할 수
있습니다(지금은 관리자가 `/update` 하는 순간에만 알림이 갑니다).

## 실시간 AIS 위치 (선택 기능)

기본적으로는 필요 없습니다 — 터미널/선사 정보와 `/watch` 알림만으로
충분합니다. 실시간 위경도까지 보고 싶으면:

1. VesselFinder API 키 발급 → 스크립트 속성 `VESSELFINDER_API_KEY`
2. `addDirectoryEntry(['선명', '별칭'], 'IMO번호', '')` 를 편집기에서
   한 번 실행해서 선박을 등록 (예시: `seedExampleDirectory()` 실행해보면 됨)

등록 안 하면 자동으로 생략되고, 터미널/선사/수동입력 정보만으로 답장합니다.

## 파이썬 버전(`vessel/`)과의 차이

| | 파이썬(`vessel/`) | 앱스 스크립트(`vessel-gas/`) |
|---|---|---|
| 실행 방식 | 서버에서 24시간 상시 실행(롱폴링) | 웹훅 — 메시지 올 때만 실행, 서버 불필요 |
| 데이터 저장 | JSON 파일 | 스크립트 자체 저장소(PropertiesService), 시트 불필요 |
| 비용 | 서버 비용 필요 | 완전 무료(구글 계정만 있으면 됨) |
| 알림(watch) | 없음(요청-응답만) | `/watch` 등록 → 갱신 시 자동 푸시 |
| 웹 조회 화면 | 챗위젯(`assets/vessel-widget.js`) | 독립 페이지(`WebApp.html`, 배포 URL 바로 열기) |
| 카카오톡 | `vessel/server.py`로 지원 | 미지원 |
| 유사도(퍼지) 매칭 | difflib 기반 | 정확일치 + 부분포함만(약간 단순화) |
