# 선박 추적 봇 — 구글 앱스 스크립트(GAS) 버전

`vessel/`(파이썬, 서버에서 상시 실행) 대신, **서버 없이** 구글 인프라에서
텔레그램 메시지가 올 때만 실행되는 웹훅 방식으로 옮긴 버전입니다.
데이터는 이 스크립트가 바인딩된 **구글 시트**에 저장돼서, 직원이
시트 셀을 직접 고쳐도 되고 텔레그램 명령어로 고쳐도 똑같이 반영됩니다.

로직은 `vessel/`의 파이썬 코드와 100% 동일하게 포팅했고, Node.js로
15개 시나리오를 시뮬레이션해서 검증했습니다(파싱, 디렉터리 매칭,
수동입력 저장·우선순위·삭제, 관리자 권한, 빈 입력 등).

---

## 배포 방법 (10분)

### 1. 구글 시트 만들고 스크립트 붙이기

1. [sheets.new](https://sheets.new) 로 새 구글 시트 생성 (이름 예: "선박추적봇")
2. 메뉴 **확장 프로그램 → Apps Script** 클릭 → 스크립트 편집기가 열림
3. 기본으로 있는 `Code.gs` 내용을 지우고, 이 폴더의 **9개 파일**을
   똑같은 이름으로 하나씩 만들어서 내용을 그대로 붙여넣기:
   - `Code.gs`, `Parser.gs`, `Directory.gs`, `Sheet.gs`, `Providers.gs`,
     `Schedule.gs`, `Formatter.gs`, `Tracker.gs`, `Setup.gs`, `Probe.gs`
   - (편집기에서 파일 추가: 왼쪽 파일 목록 옆 `+` → 스크립트)
4. 저장 (Ctrl+S 또는 💾 아이콘)

### 2. 설정값 입력 (스크립트 속성)

편집기 왼쪽 톱니바퀴 **프로젝트 설정** → 아래로 스크롤 → **스크립트 속성**
→ 속성 추가:

| 속성 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | BotFather에게 받은 토큰 |
| `TELEGRAM_ADMIN_IDS` | `/update` 등을 쓸 수 있는 chat_id (콤마구분) |
| `VESSELFINDER_API_KEY` | (선택) 있으면 실AIS, 없으면 자동 Mock |

### 3. 최초 실행 — 시트 초기화 + 토큰 확인

편집기 상단 함수 선택 드롭다운에서 `initSheets` 선택 → ▶ 실행.
- 처음 실행하면 구글이 권한 승인을 요구합니다 → 본인 계정으로 승인
  (경고 화면이 나오면 "고급" → "이동" 클릭 — 본인이 만든 스크립트라 안전)
- 실행 후 시트에 `VesselDirectory`, `ManualOverrides` 탭이 생겼는지 확인

이어서 `testGetMe` 실행 → **보기 → 실행 로그**에서 봇 정보가 찍히면 토큰 정상.

### 4. 웹앱으로 배포

1. 편집기 우측 상단 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 실행 계정: **나**, 액세스 권한: **전체(익명 사용자 포함)**
4. **배포** → 나오는 **웹 앱 URL**을 복사

### 5. 웹훅 등록

1. 스크립트 속성에 `WEBAPP_URL` 추가 (방금 복사한 URL)
2. 함수 `installWebhook` 실행 → 로그에 `{"ok":true,...}` 나오면 성공
3. 확인하려면 `getWebhookInfo` 실행

### 6. 텔레그램에서 테스트

봇에게 `HMM 코펜하겐, 0526E` 또는 `EVER GIVEN, 0526E`(시트에 예시로
들어있음) 보내보면 바로 답장이 옵니다.

## 시트로 데이터 관리하기

- **`VesselDirectory` 탭**: `Names`(콤마로 여러 별칭) | `IMO` | `MMSI` | `Note`
  — 거래하는 선박을 여기에 행으로 추가하면 바로 조회 가능해집니다.
- **`ManualOverrides` 탭**: 텔레그램 `/update`로 넣은 값이 여기 쌓입니다.
  **시트 셀을 직접 수정해도 그대로 반영**됩니다 — 직원이 텔레그램
  명령어 문법을 몰라도 엑셀 쓰듯 값만 채워 넣으면 됩니다.
  72시간 지난 행은 자동으로 무시됩니다(삭제는 안 되고 무시만 됨 —
  필요하면 `/delete`나 시트에서 직접 행 삭제).

텔레그램 명령어는 파이썬 버전과 동일합니다: `/update`, `/delete`, `/list`, `/start`.

## 터미널·선사 자동조회 — 이번엔 진짜로 될 수도 있습니다

`vessel/`(파이썬) 버전을 만든 세션은 조직 네트워크 정책 때문에
`hjnc.co.kr`, `pnitl.com` 같은 사이트에 접속이 막혀 있어서 자동조회를
완성하지 못했습니다. **하지만 이 스크립트는 배포되면 구글 인프라에서
실행되기 때문에, 그 제약이 없을 가능성이 높습니다.**

배포 후 함수 `probeAll` 을 한 번 실행해보세요 — 새로 생기는 **`Probe`**
시트 탭에 각 터미널/선사 페이지의 실제 응답(상태코드 + 본문 앞부분)이
찍힙니다. 응답이 200이고 그럴듯한 HTML/JSON이 보이면, **그 시트
내용을 캡처해서 Claude에게 다시 보여주세요** — 그걸 기준으로
`Schedule.gs`에 진짜 자동조회를 완성해드릴 수 있습니다.

(정적 HTML만 가져오는 방식이라, 페이지가 자바스크립트로 결과를
그리는 구조면 빈 뼈대만 보일 수 있어요 — 그래도 로그인 필요 여부와
서버 응답 정도는 바로 확인됩니다.)

## 파이썬 버전(`vessel/`)과의 차이

| | 파이썬(`vessel/`) | 앱스 스크립트(`vessel-gas/`) |
|---|---|---|
| 실행 방식 | 서버에서 24시간 상시 실행(롱폴링) | 웹훅 — 메시지 올 때만 실행, 서버 불필요 |
| 데이터 저장 | JSON 파일 | 구글 시트 (직접 편집 가능) |
| 비용 | 서버 비용 필요 | 완전 무료(구글 계정만 있으면 됨) |
| 웹위젯/카카오 | `vessel/server.py`로 지원 | 미지원(텔레그램 전용) — 필요하면 추가 가능 |
| 유사도(퍼지) 매칭 | difflib 기반 | 정확일치 + 부분포함만(약간 단순화) |

웹사이트 챗위젯이나 카카오톡도 GAS로 옮기고 싶으시면 말씀해 주세요 —
같은 방식(웹훅)으로 확장 가능합니다.
