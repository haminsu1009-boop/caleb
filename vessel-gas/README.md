# 선박 추적 + 알림 봇 — 구글 앱스 스크립트(GAS) 버전

서버도, 구글 시트도 필요 없습니다. 텔레그램 메시지가 올 때만
구글 인프라에서 깨어나 실행되는 **독립 스크립트**로 돌아가고,
데이터는 스크립트 자체 저장소(PropertiesService)에 둡니다.

**유니패스 알림봇처럼 동작합니다**: `/watch`로 선박을 한 번 등록해두면,
그 이후로는 다시 안 물어봐도 관리자가 `/update`로 정보를 갱신할 때마다
자동으로 알림이 옵니다.

로직은 `vessel/`(파이썬)과 같고, Node.js로 15개 시나리오를
시뮬레이션해서 검증했습니다.

---

## 배포 방법 (10분)

### 1. 독립 스크립트 프로젝트 만들기 (시트 없음)

1. [script.new](https://script.new) 접속 (구글 로그인 상태여야 함) — 바로 빈 Apps Script 프로젝트가 열립니다
2. 프로젝트 이름 정하기 (좌상단, 예: "선박추적봇")
3. 기본 `Code.gs`를 지우고, 이 폴더의 **11개 파일**을 똑같은 이름으로
   하나씩 만들어서 내용을 그대로 붙여넣기:
   - `Code.gs`, `Parser.gs`, `Directory.gs`, `Store.gs`, `Watch.gs`,
     `Providers.gs`, `Schedule.gs`, `Formatter.gs`, `Tracker.gs`, `Setup.gs`, `Probe.gs`
   - (파일 추가: 왼쪽 파일 목록 옆 `+` → 스크립트)
4. 저장 (Ctrl+S)

### 2. 설정값 입력 (스크립트 속성)

왼쪽 톱니바퀴 **프로젝트 설정** → 스크립트 속성 → 속성 추가:

| 속성 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | BotFather에게 받은 토큰 |
| `TELEGRAM_ADMIN_IDS` | `/update` 등을 쓸 수 있는 chat_id (콤마구분) |
| `VESSELFINDER_API_KEY` | (선택) 있으면 실AIS, 없으면 자동 Mock |

### 3. 토큰 확인

함수 선택 드롭다운에서 `testGetMe` 선택 → ▶ 실행. 처음 실행하면
권한 승인 화면이 뜹니다(본인이 만든 스크립트라 "고급" → "이동"으로
진행). **보기 → 실행 로그**에서 봇 정보가 찍히면 정상.

### 4. 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 유형(⚙️) → **웹 앱**
3. 실행 계정: **나**, 액세스 권한: **전체(익명 사용자 포함)**
4. **배포** → 나오는 **웹 앱 URL** 복사

### 5. 웹훅 등록

1. 스크립트 속성에 `WEBAPP_URL` 추가 (방금 복사한 URL)
2. 함수 `installWebhook` 실행 → 로그에 `{"ok":true,...}` 나오면 성공
3. 확인: `getWebhookInfo` 실행

### 6. 텔레그램에서 테스트

```
EVER GIVEN, 0526E              ← 즉시 조회 (터미널·선사 링크가 나옴, 아직 자동조회 전이라)
/watch EVER GIVEN, 0526E       ← 알림 등록
```

그다음 관리자 계정으로:
```
/update EVER GIVEN, 0526E | 터미널=HJNC | ETB=2026-09-15 08:00 | 상태=접안예정
```
을 보내면, 방금 `/watch`한 사람에게 자동으로 🔔 알림이 갑니다.

## 명령어

| 명령 | 누가 | 설명 |
|---|---|---|
| `선명, 항차` (그냥 텍스트) | 누구나 | 지금 있는 정보 즉시 조회 |
| `/watch 선명, 항차` | 누구나 | 이 선박 정보가 갱신될 때 알림 받기 등록 |
| `/unwatch 선명, 항차` | 누구나 | 알림 해제 |
| `/mywatch` | 누구나 | 내가 등록해둔 알림 목록 |
| `/update 선명, 항차 \| 키=값 ...` | 관리자 | 터미널 정보 입력 → 저장 + watch한 사람들에게 자동 알림 |
| `/delete 선명, 항차` | 관리자 | 입력값 삭제 |
| `/list` | 관리자 | 현재 저장된 입력값 전체 확인 |

`/update`로 넣은 값은 72시간 지나면 자동으로 무시됩니다(오래된
정보를 최신인 것처럼 보여주지 않기 위함).

## 터미널·선사 자동조회 — 이번엔 진짜로 될 수도 있습니다

`vessel/`(파이썬) 버전을 만든 세션은 조직 네트워크 정책 때문에
`hjnc.co.kr`, `pnitl.com` 같은 사이트에 접속이 막혀 있어서 자동조회를
완성하지 못했습니다. **하지만 이 스크립트는 배포되면 구글 인프라에서
실행되기 때문에, 그 제약이 없을 가능성이 높습니다.**

배포 후 함수 `probeAll` 을 한 번 실행해보세요 — **보기 → 실행 로그**에
각 터미널/선사 페이지의 실제 응답(상태코드 + 본문 앞부분)이 찍힙니다.
응답이 200이고 그럴듯한 HTML/JSON이 보이면, **그 로그를 복사해서
Claude에게 다시 보여주세요** — 그걸 기준으로 `Schedule.gs`에 진짜
자동조회를 완성해드릴 수 있습니다. 자동조회가 붙으면, 나중엔 시간
트리거(예: 30분마다)를 추가해서 값이 실제로 바뀔 때만 `/watch`한
사람에게 알림을 보내도록 확장할 수 있습니다(지금은 관리자가
`/update` 하는 순간에만 알림이 갑니다).

## 실시간 AIS 위치 (선택 기능)

기본적으로는 필요 없습니다 — 터미널/선사 정보와 `/watch` 알림만으로
충분합니다. 실시간 위경도까지 보고 싶으면:

1. VesselFinder API 키 발급 → 스크립트 속성 `VESSELFINDER_API_KEY`
2. `addDirectoryEntry(['선명', '별칭'], 'IMO번호', '')` 를 편집기에서
   한 번 실행해서 선박을 등록 (예시: `seedExampleDirectory()` 실행해보면 됨)

등록 안 하면 자동으로 생략되고, 터미널/선사/수동입력 정보만으로 답장합니다.

## 파이썬 버전(`vessel/`)과의 차이

| | 파이썬(`vessel/`) | 앱스 스크립트(`vessel-gas/`) |
|---|---|---|
| 실행 방식 | 서버에서 24시간 상시 실행(롱폴링) | 웹훅 — 메시지 올 때만 실행, 서버 불필요 |
| 데이터 저장 | JSON 파일 | 스크립트 자체 저장소(PropertiesService), 시트 불필요 |
| 비용 | 서버 비용 필요 | 완전 무료(구글 계정만 있으면 됨) |
| 알림(watch) | 없음(요청-응답만) | `/watch` 등록 → 갱신 시 자동 푸시 |
| 웹위젯/카카오 | `vessel/server.py`로 지원 | 미지원(텔레그램 전용) |
| 유사도(퍼지) 매칭 | difflib 기반 | 정확일치 + 부분포함만(약간 단순화) |
